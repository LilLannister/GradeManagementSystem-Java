# Grade Management System

## Overview

Grade Management System is a Java Swing desktop application developed for the SNG341 Software Construction and Evolution course.

The system allows management of students, teachers, courses, grades and academic reports using a MySQL database.

## Technologies

- Java
- Java Swing
- JDBC
- MySQL
- Apache NetBeans
- Git & GitHub

## Database Schema

Student
- ID
- Name
- Age

Teacher
- TeacherID
- Name
- Age

Course
- CourseID
- Name
- Credit

Grades
- STID
- CCode
- TID
- Grade

## Features

### Student Management
- Add Student
- Search Student
- Update Student
- Delete Student

### Teacher Management
- Add Teacher
- Search Teacher
- Update Teacher
- Delete Teacher

### Course Management
- Add Course
- Search Course
- Update Course
- Delete Course

### Grades Management
- Add Grade
- Search Grade
- Update Grade
- Delete Grade

### Reports
- Search Student Grade
- Best Student In Course
- Student Average Grade
- Courses With More Than N Students
- Teachers Without Any Courses
